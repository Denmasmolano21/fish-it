# 🎣 DEN HUB - Fish It Script

Advanced Fishing Automation Hub untuk game **Fish It** di Roblox dengan fitur lengkap untuk meningkatkan pengalaman bermain.

---

## ✨ Fitur Utama

### 🎣 Auto Fishing System
- **Auto Fish**: Otomatisasi penuh sistem penangkapan ikan
- **Perfect Cast**: Mode casting presisi untuk hasil maksimal
- **Rod Detection**: Deteksi otomatis jenis rod dengan delay yang sesuai
- **Custom Delay**: Atur delay custom sesuai kebutuhan
- **Bypass Delay**: Delay khusus untuk bypass protection

### ⭐ Auto Favorite
- Lindungi ikan berharga secara otomatis
- Support untuk: Secret, Mythic, Legendary, Epic
- Prevent accident selling valuable fish

### 💰 Auto Sell System
- Jual ikan secara otomatis saat mencapai threshold
- Threshold default: 60 items
- Smart filtering (hanya jual non-favorited items)

### 🗺️ Teleport System
- **Island Teleports**: Teleport ke berbagai pulau
  - Weather Machine
  - Esoteric Depths
  - Tropical Grove
  - Stingray Shores
  - Kohana Volcano
  - Coral Reefs
  - Crater Island
  - Winter Fest
  - Dan masih banyak lagi...

- **Event Teleports**: Teleport langsung ke event aktif
  - Shark Hunt
  - Ghost Shark Hunt
  - Worm Hunt
  - Black Hole
  - Shocked
  - Ghost Worm
  - Meteor Rain

### 🔧 Utility Features
- **Auto Enchant Rod**: Otomatisasi enchanting rod
- **Boost FPS**: Optimasi grafis untuk performa lebih baik
- **Server Hop**: Pindah server otomatis untuk cari yang kosong
- **Rejoin Server**: Rejoin server saat ini
- **Anti-AFK**: Sistem anti-AFK otomatis

## 📖 Cara Penggunaan

### Auto Fish

1. Buka script dan tunggu UI muncul
2. Klik toggle **"Auto Fish"** untuk mengaktifkan
3. Script akan otomatis:
   - Detect rod yang Anda gunakan
   - Menangkap ikan dengan timing sempurna
   - Menggunakan delay yang sesuai untuk setiap rod

### Auto Favorite

1. Aktifkan toggle **"Auto Favorite"**
2. Ikan dengan tier Secret, Mythic, Legendary, Epic otomatis dilindungi
3. Tidak akan terjual saat menggunakan Auto Sell

### Auto Sell

1. Aktifkan toggle **"Auto Sell"**
2. Saat ikan non-favorited mencapai 60, otomatis terjual
3. Hanya jual ikan yang tidak di-favorite

### Teleport

1. Buka tab **"Teleports"**
2. Pilih island atau event dari dropdown
3. Klik untuk teleport

### Server Hop

1. Buka tab **"Utility"**
2. Klik **"Server Hop"** untuk pindah ke server dengan pemain lebih sedikit
3. Otomatis teleport ke server baru

## 🔧 Troubleshooting

### Auto Fish Tidak Berfungsi

- Pastikan Anda sudah equip rod
- Cek apakah delay sudah terdeteksi dengan benar
- Coba manual set delay di input field

### Teleport Error

- Pastikan lokasi/event tersedia di game
- Tunggu 2-3 detik sebelum teleport lagi
- Restart script jika masalah persisten

### FPS Masih Lambat

- Klik "Boost FPS" di utility tab
- Matikan graphics setting yang tidak perlu
- Gunakan executor dengan memory management baik
